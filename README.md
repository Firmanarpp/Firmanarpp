- Mengembangkan modul autentikasi, dashboard pemantauan aset, dan fitur CRUD manajemen data barang/ruangan
- Mengintegrasikan fitur pemindai QR Code untuk pelacakan fisik aset secara real-time

- Memberikan dukungan teknis instalasi dan troubleshooting perangkat lunak INLISLite (Perpusnas)

**Pencapaian:** Berhasil mendeploy platform terpusat yang mentransformasi pengelolaan aset dari sistem manual (spreadsheet) menjadi sistem digital, secara signifikan meningkatkan efisiensi waktu, akurasi data, dan akuntabilitas inventaris KPU.

`Laravel` `Tailwind CSS` `Figma` `MySQL` `QR Code` `PWA`
